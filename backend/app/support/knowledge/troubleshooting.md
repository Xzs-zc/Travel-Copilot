# Travel Copilot 故障排查手册

故障排查应先确认页面类型、景区 POI、当前加载状态和系统配置，再给出原因与下一步。不能仅根据用户描述断言服务故障。

## 中国地图黑屏

地图依赖高德 JS Key 与安全密钥。出现黑屏时先确认前端配置接口是否成功返回高德配置，再正常刷新页面。

如果配置缺失，页面会显示配置提示而不是地图。如果配置存在但仍黑屏，可能是 JS API 加载失败、浏览器网络异常、安全密钥不匹配或缓存仍指向旧前端资源。

## 省份地图没有光点

进入省份后，热门景区请求需要一定时间。光点可能在省份区域加载后稍晚出现，这不等同于地图失效。

若长时间没有光点，应检查省份 adcode、热门景区接口、后端日志和高德 Web 服务配置。不要建议用户重复点击省份造成重复请求。

## 景区资料加载慢

景区页会先返回高德基础资料，再补充官网核验、天气、图片和 DeepSeek 摘要。首次生成通常比缓存命中慢。

后台准备任务会在用户悬停景区光点或进入页面时启动。离开页面不一定会取消任务，再次进入时可能回放已有事件并继续等待结果。

## 图片完全没有显示

检查图片地址是否可访问、本地媒体缓存是否存在、景区后台任务是否完成，以及画廊是否返回了有效候选。

若画廊为空，可以重新加载；若数据库或媒体目录不可用，需要检查后端服务与 `data/media`。不要展示环境变量值或完整异常堆栈。

## 图片模糊

图片模糊可能来自原始素材分辨率低、服务端压缩、浏览器展示尺寸过大，或候选图片本身不是高质量实景图。

系统会优先主图准确性，但官方页面也可能提供低分辨率图片。画廊会做尺寸和语义筛选，降低门槛补足数量时可能出现质量一般的图片。可以建议刷新、重新生成或优先查看清晰度较高的画廊图片。

## 图片重复或与景区不匹配

系统会通过感知哈希去重，并使用视觉模型判断图片与景区名称、城市的语义匹配。去重和视觉检查不能保证百分之百正确。

不匹配可能来自同名景点、附近 POI、城市级通用图或公共图片元数据错误。应向用户说明图片来源和筛选策略，不应在没有证据时声称某张图百分百准确。

## 页面显示 undefined 或空字段

`undefined` 通常表示前端拿到的结构与预期不一致，或某项异步数据尚未返回。应核对接口响应字段、缓存版本和页面状态。

单个字段缺失不应导致整页空白。票价、开放时间、天气等非关键字段允许为空，并使用“待确认”或“暂无数据”表达。

## 景区后台任务失败

后台任务可能因高德、官网、图片下载、视觉模型或超时失败。任务失败时应保留基础资料并明确说明哪一部分未完成。

如果错误可重试，可以提供重新加载建议；如果缺少配置，应指出配置类型但不能展示密钥内容。

## 交通方案加载失败

优先检查出发地是否填写、目的地是否有效、12306 查询是否返回、路线服务是否可用。

铁路无票或无直达不等同于系统故障。系统在可行时会继续分析中转或航班，但不会保证一定存在方案。
