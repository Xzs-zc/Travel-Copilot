# 常见问题与术语说明

本文解释 Travel Copilot 中常见的产品术语和能力边界。回答时应说明“当前能做什么、为什么这样设计、哪些信息需要用户复核”，不要把产品说明写成技术实现细节。

## POI 是什么

POI 是 Point of Interest 的缩写，表示地图中的兴趣点。景区、公园、车站、机场和餐馆都可能是 POI。

Travel Copilot 使用高德 POI ID 定位具体景区。POI ID 比景区名称更适合作为定位依据，因为不同城市可能存在同名地点，名称也可能包含简称、别名或错别字，而服务商内的 POI ID 能指向一个明确实体。POI 与 adcode 解决的问题不同：POI 用于定位单个地点，adcode 用于定位行政区。

## adcode 是什么

adcode 是行政区划代码。中国地图和省份地图使用 adcode 标识省、市等行政区域，并据此加载区域边界、切分地图和请求该区域的景区数据。

用代码而不只用省份名称，是因为名称可能出现简称、同名区域、文本格式差异或输入不统一；标准代码更便于稳定匹配、接口传参和前后端缓存。adcode 表示行政区域，不表示某个景区的坐标，也不能替代 POI ID。

## 为什么热门景区只有 7 个

每个省通常展示约 7 个热门景区，主要目的是保持地图可读性。若把全部 POI 都铺在地图上，光点会重叠，用户也难以比较和点击。

候选池来自高德景区数据，再结合用户山水、人文或均衡偏好和 DeepSeek 排序生成展示结果。7 个是页面展示上限，不代表该省只有 7 个景区；候选不足、景点名称过度集中或排序变化时，具体景区也可能不同。热门推荐只用于旅行前筛选，不保证景区开放或适合用户。

## 为什么没有酒店规划

当前项目只做旅行前的景区发现和交通比较，不查询酒店库存、房价、评分、预订或入住安排，也不提供酒店下单入口。

“没有酒店规划”不等于酒店信息永远无关，而是当前产品把范围限定在景区选择和到达方式。客服应直接说明边界，可以建议用户到正规 OTA 或酒店官方渠道查询，但不能编造酒店推荐、空房或价格。

## 为什么没有每日行程

项目目标是帮助用户选择景区、理解景区资料并比较到达方式，不负责把每天上午、下午和晚上安排成完整路线，也不替代专业行程编排工具。

页面可以提供交通耗时、天气和景区信息，供用户自行安排顺序；这些信息不构成完整日程，也不代表景点之间已经验证了最优游览顺序。旅行过程中的实时导航、临时改线和到店导航同样不在当前范围内。

## 为什么看不到具体车次

页面使用聚合余票时段帮助用户比较“哪个出发时段更有机会”，不展示具体车次号和购票入口。这样能降低把瞬时、易变化的余票摘要误当成最终库存的风险。

聚合时段与具体车次不同：时段只表示某段时间的整体参考情况，不能说明某一趟车一定有余票，也不能代替 12306 的实时结果。系统应提示用户到 12306 等官方渠道核对车次、余票、票价和购票规则，不能生成不存在的车次或声称已经锁票。

## 为什么图片有时很少

不同景区的公开高质量图片数量差异很大。系统会先保证实体匹配、来源可追溯和重复控制，再尽量补足约 6 张画廊图片。

当素材不足时，系统可以适度降低分辨率门槛或扩展候选池，但不应为了凑数重复同一张图，也不应把其他景区、附近 POI 或语义不匹配的图片放进来。因此“少于 6 张”可能是正常结果。少量可信图片通常比数量充足但重复、模糊或错误的画廊更可靠。

## 为什么项目需要登录才能使用客服记忆

登录用于识别账户、隔离不同用户的客服会话，并保存山水/人文偏好。客服消息记录包含上下文和已给出的回答，必须绑定到明确账户，才能避免不同用户互相读取。

未登录时仍可浏览地图、景区和交通规划，但客服无法可靠恢复之前的长期对话，也不能把匿名状态当作永久身份。即使用户已登录，也不应在聊天中提交密码、验证码、身份证号、银行卡或 API Key；系统不会展示其他用户的会话，也不会用登录状态绕过第三方平台限制。

## 什么是官方核验

官方核验表示系统尝试从景区官网、文旅局或其他公开官方页面读取开放时间、票价和预约等关键信息，并与基础资料进行对照。

“已核验”表示找到了一条可追溯的官方来源，不表示全天候实时有效，也不保证所有字段都没有变化。若官网与高德开放时间冲突，应展示各自来源和更新时间，并把不能确认的字段标为“待确认”；若没有官方来源，高德基础资料仍可帮助识别景区，但票价和开放规则不能因此自动升级为官方结论。

## 数据多久更新

景区详情、热门景区、官网摘录、12306 查询、航班、天气和图片使用不同的缓存周期，因此同一页面上的字段新鲜度并不完全相同。

天气、余票、航班价格和运行状态变化最快，缓存只适合减少重复请求和改善加载，不代表实时库存。官网开放时间、票价和预约规则可能因季节、节假日或临时公告变化，出发前仍应复核。回答时应说明数据来源和时效，不要用“昨天看到一样”推断今天仍然相同。
